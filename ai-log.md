- Before project start: Claude helped me write the project plan in English, including the MoSCoW list, sprint plan and risk table. I corrected, among other things, that GSAP does not work in React Native (Reanimated is used instead) and that the project is five weeks, not six.

- 2026-10-12: Claude drafted issues per sprint (`issues.md`) from the sprint plan. I adjust them myself and create the milestones and dates in GitHub.

- 2026-10-12: discussed the license with Claude. I chose "All rights reserved" for the code, and decided that images and stories are not covered by any license. I wrote the README text myself, based on a suggestion.
- 2026-10-20: Chose the OpenAI API model for story generation (issue 14, step A). Compared gpt-4.1-mini, gpt-5.4-mini and gpt-5.5 with the same prompt on five themes, using a comparison script that lists the models available to my API key instead of guessing names. gpt-4.1-mini was dropped after the first run (too short, language errors, stated the lesson outright). gpt-5.4-mini followed the format and was cheap (about $0.003 per story), but the stories were thinner and sometimes stated the lesson. gpt-5.5 wrote the most original stories and showed the lesson through the plot (about $0.023 per story, roughly $8–9 per year with one story a day). Chose gpt-5.5. API cost for the comparison: about $0.25.
- 2026-10-27: Decided how the archive shows dates. Today's story stays in the archive but is labelled "I dag" instead of a date. Other stories show the date in Swedish ("21 oktober"), read as UTC so it doesn't show the day before in other time zones. Also came up with the idea of a short summary for each story in the archive. Claude helped estimate the work, and it was added as a new Should issue (47) instead of being done now, since the Must issues in sprint 3 come first.

## Code control, validation, reviews, security

_E.g. how AI suggestions were reviewed before going into the code, security reviews, what was changed manually afterwards._

- 2026-10-12: removed the MIT `LICENSE` from the Expo template in `mobile/`, so that only the license in the repo root applies.
- 2026-10-12: installing `@expo/ngrok` produced 30 vulnerability warnings (mostly older dependencies in a development tool). I did not run `npm audit fix --force`, because it can break the project. To be reviewed again before submission.
- 2026-10-17: Updated prisma, @prisma/client and @prisma/adapter-pg together to 7.10.1 instead of running npm audit fix, which would only have updated the CLI.
- 2026-10-20: Iterated on the prompt during the comparison. gpt-5.5 put every sentence in its own paragraph, which would look fragmented in the app. A first fix ("short paragraphs, 2–4 sentences") did not work. I noticed that "a blank line between every paragraph" was probably read as "after every sentence", and made the rule explicit, which fixed it in all following runs. Also noticed that both models reused the same names (Rillo, Mira, Snäckis), which confirms that the list of characters to avoid is needed.
- 2026-10-21: Supabase warned that the stories table was publicly accessible (RLS disabled). The Data API turned out to be on, although I believed it was off. Turned it off, checked that the data was intact and that the project URL was never in git, and enabled RLS on all tables with a Prisma migration. Added a rule to constraints.md that every new table gets RLS.

## Other necessary or interesting information

_E.g. token limits hit, AI going wrong, unexpected situations and how they were solved._

- 2026-10-12: connecting a phone through `expo start --tunnel` in WSL did not work. The global install of `@expo/ngrok` failed because of permissions, and after a local install ngrok returned an empty response. Claude suggested WSL "mirrored networking" as an alternative. I am postponing the phone test and continuing with the web preview (`w`) for now.
- 2026-10-12: React Native DevTools reported a missing `libnspr4.so`. Claude explained that it is not critical, and I have not fixed it.
- 2026-10-17: Deployed the backend to Vercel (issue 8). The build failed three times before it worked: the generated Prisma client is not in git (fixed by running `prisma generate` in the build script), `prisma generate` requires `DIRECT_URL` (added it as an environment variable in Vercel, since it uses the same credentials as `DATABASE_URL`), and Vercel's TypeScript step could not find `@types/node` (fixed by setting `typeRoots` in tsconfig.json). Skipped Vercel's suggested Prisma Postgres integration, since the project already uses Supabase.
- 2026-10-18: Got the app running on a real phone via Expo Go (issue 2) by turning on WSL mirrored networking and adding a Hyper-V firewall rule for port 8081. The earlier tunnel attempt (ngrok) was dropped, and @expo/ngrok was uninstalled.
- 2026-10-20: Several stories seemed to have missing spaces between words. Writing the output to a file instead of copying from the terminal showed that the spaces were there: the WSL terminal drops the space where it wraps long lines when you copy. The model was not at fault.
- 2026-10-27: Expo Go on my phone updated itself to SDK 58, and could no longer open the project, which uses SDK 57. Instead of upgrading the project in the middle of the sprint, I installed Expo Go for SDK 57 from expo.dev/go and turned off automatic updates. Upgrading the SDK is left until after the thesis, or until there is a calm moment, on a separate branch.
